# 🌐 專案網址總覽

## 🏠 本地開發環境

### 前端
- **首頁**: http://localhost:3000
- **房源列表**: http://localhost:3000
- **房源詳情**: http://localhost:3000/listing/[id]
- **發布房源**: http://localhost:3000/create
- **登入**: http://localhost:3000/login
- **註冊**: http://localhost:3000/register
- **Admin Panel**: http://localhost:3000/admin
  - 儀表板: http://localhost:3000/admin
  - 房源管理: http://localhost:3000/admin/listings
  - 使用者管理: http://localhost:3000/admin/users
  - 審核日誌: http://localhost:3000/admin/audit

### 後端 API
- **API 根路徑**: http://localhost:4000
- **API 文件 (Swagger)**: http://localhost:4000/api-docs
- **健康檢查**: http://localhost:4000/health
- **認證 API**: http://localhost:4000/api/auth
- **房源 API**: http://localhost:4000/api/listings
- **搜尋 API**: http://localhost:4000/api/search
- **上傳 API**: http://localhost:4000/api/uploads
- **管理員 API**: http://localhost:4000/api/admin

## 📊 監控與追蹤

### Sentry (錯誤追蹤)
- **Dashboard**: https://sentry.io
- **建立專案**: https://sentry.io/organizations/[org]/projects/new/
- **API Keys**: https://sentry.io/settings/[org]/api-keys/
- **Alerts**: https://sentry.io/settings/[org]/alerts/

### 日誌檔案
- **錯誤日誌**: `packages/backend/logs/error.log`
- **所有日誌**: `packages/backend/logs/combined.log`
- **例外日誌**: `packages/backend/logs/exceptions.log`
